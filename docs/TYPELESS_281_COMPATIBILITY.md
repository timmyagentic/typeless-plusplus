# Typeless 2.8.1 兼容验证

日期：2026-10-06，macOS / Apple Silicon。官方安装版本为 2.8.1（2.8.1.130）。
基线为已合并 PR #10 的主分支提交 `4f64e73`。

## 实测与修复

- 当前会话仍能按原格式读取，官方账户页显示已登录；接口却返回 HTTP 403，并明确说明
  不支持第三方客户端。已区分 401 登录失效、普通 403 和该固定拒绝响应。不复刻客户端
  安全签名，不刷新或注入会话，不修改官方应用或存储。
- 明确拒绝第三方客户端后，停止同一会话的事件重试。手动刷新或会话变化可按冷却规则
  重新查询。只回退到仍在运行的官方客户端、已确认身份、新鲜且来源为 Accessibility 的
  周额度；本地猜测、待核对、需要重启、过期快照和其他鉴权失败不能启用该回退。
- 官方 2.8.1 账户页把账户、邮箱和订阅合并成一个文本节点。新增识别仍要求官方 hub 文档
  和真实账户、设置、退出按钮，拒绝历史文本、其他文档及互相冲突的身份。换号后的重启
  隔离规则继续生效。
- 版本读取直接读取安装包 Info.plist，避免常驻管理器因 Bundle 缓存长期显示旧版。
- 官方首页可见额度为 106 / 2,000；额度上限取自实际来源，没有写死旧版的 8,000。

## 使用与范围

遇到第三方接口限制后，根据应用提示结束录音、正常重启 Typeless，打开设置 → 账户核对
邮箱，再回主页读取额度。若官方主窗口没有暴露可读的 AX 内容，继续显示未知；不会用
旧主页数字填补缺口。活动状态未知时，自动守护仍暂停切换。

此变更是源码与本地候选验证，不代表正式发布、公证、更新 feed 推送或已安装应用升级。

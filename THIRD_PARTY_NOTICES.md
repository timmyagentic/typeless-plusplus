## Typeless session format reference

`OfficialQuotaSessionReader.swift` is a native Swift implementation of the current-session
file format documented by [fufu1209/Typeless](https://github.com/fufu1209/Typeless/blob/f26f798eb7d9ff4331334f3d0725d17c629368d0/scripts/extract-active-session.js).
It reads the current session for a user-enabled, read-only quota request. It does not include
that project's token export, device reset, registration, or session injection features.
